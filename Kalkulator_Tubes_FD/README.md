# Kalkulator Rubrik Penilaian Tugas Besar

Aplikasi Streamlit untuk menghitung total poin berdasarkan rubrik penilaian Tugas Besar.

## Menjalankan di komputer

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy ke Streamlit Community Cloud

1. Upload semua file dalam folder ini ke repository GitHub.
2. Buka Streamlit Community Cloud.
3. Pilih repository dan branch yang berisi proyek ini.
4. Set **Main file path** menjadi `app.py`.
5. Klik **Deploy**.

File `rubric_data.py` harus berada di folder yang sama dengan `app.py`.
